no contact form. no newsletter capture. no "let's hop on a quick call" funnel. one channel, and it's the one i actually check.

## github

[github.com/marshallhouston](https://github.com/marshallhouston). open an issue, start a discussion, comment on a repo. that's the address.

for anything about this site specifically, the repo is [marshallhouston/marshallhouston.wtf](https://github.com/marshallhouston/marshallhouston.wtf). broken link, wrong date, a post that reads like it was written by a language model with a quota to hit: file it there. corrections land faster than compliments, which is how it should be.

for the tools, [cosmic farmland](https://github.com/marshallhouston/cosmic-farmland) is where the plugins and scripts live. issues there too.

## comments

every post has comments at the bottom, powered by giscus, which is github discussions wearing a different hat. if the thing you want to say is about a specific post, say it under that post. it stays with the writing instead of disappearing into a dm.

## what i'm likely to answer

- something i got wrong, with the correction
- a pointer to writing or a person i should read
- a question about how i actually work with agents day to day

## what i'm not

- available for sponsored posts (see [about](/about))
- a consultant, a coach, or a growth partner
- fast. i respond in bursts, not in threads.
